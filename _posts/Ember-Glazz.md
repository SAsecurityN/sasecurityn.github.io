As you might know, I had created my own Obsidian theme before (SAzure Glass) - a post on it you can find here: https://sasecurityn.github.io/creations/2026/08/14/SAzure-Glass.html
Yet, the thing is, after using *SAzure Glass* for a bit, either I got too used to it, but I wanted a darker theme, in colors that I like - so I decided to create another theme. 

The new theme is "Ember Glazz", take a look:

**Reading mode**:
![img](/assets/img/showcase3.png)

**Live preview mode**:
![img](/assets/img/showcase.png)

![img](/assets/img/showcase2.png)


Features:
- Frosted glass panels
- Adjustable glass blur and transparency via Style Settings plugin
- Six different colored heading bars (From heading 1 to heading 6)
- Crimson terminal-style inline code and code blocks
- Gem-style horizontal rule divider
- Tag pills, tables, and blockquotes tuned for the darker and crimson look

Recommended settings:
![Settings](/assets/img/settings2.png)

## You can download/add the theme here:
[Ember Glazz on the Obsidian community themes](https://community.obsidian.md/themes/ember-glazz)


*Or just navigate to `Settings` in Obsidian, `Appearance` -> `Themes` -> `Manage` -> Search for "SAzure Glass" and install it.*
