## About

![showcase](/assets/img/chain-showcase.gif)
It was summer 2026 - I was solving some labs that had heavy amount of moving through networks and had no decent way to visualize them and the progress, their types, their status, chain them - so I started building **latveriux**. 
Then, I found myself being given numerous targets for pentest engagement, yet no way to bulk-add them and update their status/write notes on them, all at the same time - so I added "hosts" which lets you bulk-add hosts to the app. 
Furthermore, I added built-in terminal support as well - so terminal is right there, without having to leave the app. **Beware** - metasploit might not work in the built in terminal, if that happens, just press CTRL + C. 
Finally, you can even add notes right there - the tool has many functions and little things that should make your work both easier and faster!

## Installation

**Prerequisites**:

- `Python 3.8` or newer
- `pip`
- `PyQt5`

```
git clone https://github.com/SAsecurityN/latveriux.git
cd latveriux
```
